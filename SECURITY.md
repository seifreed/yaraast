# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| `main` / upcoming 2.0 | Yes |
| 1.x | No |

## Reporting

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/seifreed/yaraast/security/advisories/new)
and include the affected version, impact, reproduction steps, and any proposed
fix. You should receive an acknowledgement within seven days. Coordinated
disclosure timing will be agreed after impact and remediation are understood.

Security fixes are released without preserving unsafe legacy behavior.
